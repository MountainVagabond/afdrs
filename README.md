# Tasmania AFDRS Dashboard (Bootleg/Unofficial)

A private, personal map tool. The page opens only with an access key; this repository
holds the page alone, with no data and no keys.

Unofficial: not authorised or endorsed by, or affiliated with, any fire agency or the
Bureau of Meteorology. May be shared, by invitation only, with individuals who are
already well informed about bushfire risk, and used at their own risk. Personal
judgement, knowledge and experience should be applied when viewing this tool. Use
alongside official forecasts and warnings, not instead of them.

All effort and care has been taken in the development of this tool, but its accuracy
and currency are not guaranteed, and there are known lags in the system while
information from official sources is being updated.
